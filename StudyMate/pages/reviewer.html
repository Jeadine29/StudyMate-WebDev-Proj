Topic: Introduction to HTML

HTML: HyperText Markup Language is used to structure content on web pages.

HTML Element: An element consists of an opening tag, content, and sometimes a closing tag.

Heading: The h1 to h6 tags define headings.

Paragraph: The p tag defines a paragraph.

Link: The a tag creates a hyperlink.

Important HTML Tags

HTML Tag Purpose Example
h1 Main heading <h1>Hello</h1>
p Paragraph <p>Hello</p>
a Hyperlink <a href="index.html">Home</a>
img Display an image <img src="photo.jpg" alt="Photo">
